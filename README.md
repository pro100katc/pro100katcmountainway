# My Mountain Way

Адаптивний персональний сайт і блог про походи, гори, витривалість та подорожі. Підтримує українську, англійську та словацьку мови.

## Як запустити
1. Розпакуйте архів.
2. Відкрийте `index.html` у браузері або завантажте всі файли на вебхостинг.
3. Для локальної розробки зручніше скористатися VS Code та розширенням Live Server.

## Що потрібно персоналізувати перед публікацією
- Замінити демонстраційні фотографії на власні.
- Додати реальні походи, дати, маршрути, дистанції та набори висоти.
- У `index.html` замінити `href="#"` на адреси Instagram, Facebook, YouTube, Garmin Connect і TikTok.
- За потреби додати окремі сторінки для кожного походу, GPS-треки GPX та інтеграцію з картою.
- Перевірити метадані, favicon та контактну адресу.

## Домен
Рекомендована назва: `mymountainway.com`, якщо вона доступна. Альтернативи: `mymountainway.net`, `mymountainway.eu`, `my-mountain-way.com`. Доступність потрібно перевірити в реєстратора безпосередньо перед реєстрацією.
